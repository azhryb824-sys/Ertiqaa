# شموس V2 — الإصدار المطور المعزول

## حدود الأمان

- النسخة الأولى تستمر عبر `dashboard.html` ومفاتيح `misad*` الأصلية.
- V2 يعمل من `/v2/index.html` ويستخدم API مستقلًا تحت `/api/v2/*`.
- يجب ضبط `V2_BACKUP_KEY` بسر عشوائي طويل وثابت في بيئة الإنتاج. تُشفّر النسخ الاحتياطية بـ AES-256-GCM، ولا ينبغي تغيير المفتاح دون خطة تدوير تحفظ إمكانية فك النسخ السابقة.
- فحص الاستعادة غير المتلف متاح للمالك/المشرف عبر `POST /api/v2/restore-drill`؛ يفك آخر نسخة في الذاكرة، ويتحقق من وسم المصادقة وSHA-256 والبنية، ولا يكتب شيئًا إلى التخزين.
- قبل أي عرض تجاري اضبط `V2_AUTH_KEY` بسر ثابت مستقل و`V2_STRICT_AUTH=true`. عندها يرفض V2 جلسة النسخة الأولى ويقبل فقط جلسة V2 قصيرة العمر بعد كلمة المرور وTOTP.
- التهيئة الأولى تبدأ من جلسة النسخة الأولى الموثقة عبر واجهة V2، ثم تُنشأ كلمة مرور جديدة وMFA خاصان بـV2. سر MFA ورموز الاستعادة لا تظهر إلا أثناء التهيئة.
- تخزين الخادم مستقل في `<DATA_DIR>/v2/storage.json` مع نسخ احتياطية في `<DATA_DIR>/v2/backups/`.
- التهيئة تنسخ لقطة قراءة من V1، ولا تستدعي أي نقطة كتابة تخص V1.
- قيود اليومية وسجل التدقيق إلحاقيان؛ حذف القيود أو إعادة كتابتها مرفوض خادميًا.
- الحذف التشغيلي في الواجهة أرشفة منطقية، وتُرفض أرشفة العقد عند وجود أثر مالي نشط.

## الوحدات

- مركز القيادة والتشغيل.
- CRM والعملاء.
- العقود ومستويات الخدمة SLA.
- البلاغات وأوامر العمل والزيارات.
- الأصول والصيانة ومؤشرات الجاهزية لـ MTBF/MTTR وIoT.
- المخزون والمشتريات والموردون.
- الموظفون والرواتب والعهد.
- المحاسبة والذمم والقيود.
- الرقابة والامتثال وسجل التدقيق.
- التحليلات والتقارير وإعدادات V2.
- PWA مستقلة تعمل بواجهة Offline ولا تخزن استجابات API الحساسة في Service Worker.

## نموذج التزامن

كل منشأة لها `version` مستقل. عملية الحفظ ترسل النسخة المتوقعة؛ إذا سبقها مستخدم آخر يرجع الخادم `409` ويطلب إعادة التحميل، بدل الكتابة فوق البيانات الأحدث.

## بوابات الاعتماد

1. نجاح اختبارات `v2-isolation`, `v2-store`, و`v2-accounting`.
2. نجاح اختبار API: تهيئة V2 وكتابة حالة مستقلة مع ثبات بصمة ملف V1.
3. رفض حذف قيد مرحل عبر API بحالة `409`.
4. لا يتم دمج الفرع أو نشره قبل مراجعة المستخدم.
5. لا يتم تحويل V2 إلى قاعدة الإنتاج إلا بترحيل مستقل قابل للتراجع ونسخة احتياطية مجربة.
