# تطبيق ارتقاء لسطح المكتب

يشغّل التطبيق النظام نفسه وقاعدة `storage.json` محلية داخل مجلد بيانات المستخدم. يعمل الحفظ والقراءة محليًا دون إنترنت، ويجري محرك المزامنة محاولة كل 30 ثانية.

## إعداد المزامنة

يجب ضبط القيمتين نفسيهما في خدمة الإنترنت وعلى جهاز سطح المكتب:

```text
DESKTOP_SYNC_TOKEN=<random-secret-at-least-32-bytes>
ERTIQAA_REMOTE_URL=https://ertiqaa.onrender.com
```

لا يوضع رمز المزامنة في المستودع أو داخل ملف التثبيت.

## قواعد السلامة

- في أول تشغيل متصل تُسحب قاعدة الإنترنت إلى الجهاز قبل إظهار شاشة الدخول.
- التعديلات اللاحقة ترفع كل 30 ثانية.
- السجلات المصفوفية تندمج حسب `id` وبالاعتماد على آخر نسخة مزامنة.
- عند انقطاع الإنترنت يستمر الحفظ محليًا وتظهر حالة «دون اتصال · الحفظ محلي».
- يحتفظ `sync-baseline.json` بخط الأساس اللازم لاكتشاف التغييرات والتعارضات.
